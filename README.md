# OPIc 5-5 IM2 최소암기 스크립트

34개 주제 섹션과 168개 질문을 연습하는 정적 웹페이지입니다. 설문조사 기반·일반/돌발·롤플레이 문항을 포함하며, 현재 168개 질문 모두 영어·한국어 질문과 완성 답변을 제공합니다.

- [전체 스크립트](https://sh0427-han.github.io/opic_script/#scripts)
- [문제 연습](https://sh0427-han.github.io/opic_script/#questions)
- [핵심 암기](https://sh0427-han.github.io/opic_script/#core)
- [시험 전 설문](https://sh0427-han.github.io/opic_script/#survey)

롤플레이는 17개 주제별 섹션과 필터로 구분합니다. 같은 주제의 정보 문의·문제 해결·관련 경험 문항은 한 섹션 안에서 이어서 연습합니다. 설문 기반 9개와 일반·돌발 8개를 합쳐 전체 34개 섹션입니다.

## 추가 롤플레이 질문

친척집 돌보기·약속 경험, 새 휴대전화 구매·교환, 새 술집 방문·약속 변경을 각각 3문항 세트로 추가했습니다. 현재 9개 문항 모두 완성 답변까지 작성되어 있습니다. 사용자가 제시한 상황을 바탕으로 작성한 연습 문항이며 실제 기출 원문으로 검증되지 않았습니다. 친척집 열쇠 문항은 친척이 머무는 호텔 프런트에 메시지를 남겨 도움을 요청하는 상황으로 구성했습니다.

공개 예시에서 상황과 유형을 대조했습니다: [친척집·호텔 연락](https://knowledgeismoney.tistory.com/115), [새 술집·불참](https://knowledgeismoney.tistory.com/107?category=1055550), [구매·문제 해결 역할극 유형](https://mansour.tistory.com/entry/roleplay-questions). 개인 학습 자료이며 공식 문제은행이나 출제 빈도의 근거로 사용하지 않습니다. 휴대전화 단순 불만족으로 인한 교환 세트와 각 세 번째 경험 질문은 사용자 요청을 바탕으로 독자적으로 구성했습니다.

## v42 변경 사항

- `script-data.js` 기준 버전을 v42(2026-10-08)로 갱신했습니다.
- 추가 롤플레이 9개를 포함해 현재 168개 질문 모두 완성 답변을 제공합니다.
- 해변 문제 경험을 공원·국내여행·휴대폰 문제 경험과 같은 흐름인 ‘휴대폰을 떨어뜨림 → 전원 꺼짐 → 전원 버튼을 여러 번 누름 → 다시 켜짐’으로 통일했습니다.
- 펍 변화·비교 답변은 현재 설정에 맞춰 ‘대학생 때 친구들과 방문 → 요즘은 주말에 혼자 조용한 펍 방문’으로 수정했습니다.
- 집에서 보내는 휴가 Q6은 질문 의도에 맞게 ‘휴가가 필요한 이유와 휴식의 효과’를 직접 설명하도록 수정했습니다.
- 학습 우선순위는 설문조사 기반 필수 문항을 먼저 안정화한 뒤 변형·꼬리 질문, 롤플레이, 돌발 질문 순으로 확장하도록 정리했습니다.
- 답변 길이는 대부분 5~7문장이며, 현재 분포는 4문장 3개, 5문장 32개, 6문장 128개, 7문장 4개, 8문장 1개입니다. 문장 수보다 질문 요구에 맞게 끝까지 답하는 것을 우선합니다.

## v40 변경 사항

- 159개 답변을 쉬운 회화체로 다시 다듬었습니다. 너무 짧게 끊긴 문장은 상황·이유를 보태고 `and`, `but`, `so`, `because`로 연결했습니다.
- `Well`, `you know`, `I mean`, `Honestly`는 맥락에 맞는 곳에서 사용합니다. 모든 답변을 같은 필러로 시작하거나 의미 없는 말로 길이를 채우지 않습니다.
- 공통 문장과 핵심 표현 43개의 한국어 뜻도 새 답변과 맞췄습니다.

- 159개 문항에 영어 질문과 의미가 일치하는 한국어 번역을 작성했습니다.
- 질문의 세부 요구를 명확히 하고 답변과 대조했습니다. 과거 경험은 사건·행동·결과, 정보 문의는 요청한 질문 수, 문제 해결 역할극은 구체적인 대안을 포함합니다.
- v40 당시 답변은 5문장 23개, 6문장 134개, 7문장 2개였습니다. 현재 길이 분포는 위 v42 변경 사항을 따릅니다. 선택 문장 구분과 접기 기능은 제거했습니다.
- 묘사·일과·과거 경험·문제 경험·비교·의견·롤플레이를 유형별로 묶었습니다. 묘사에는 외형·구성·분위기, 일과에는 평소 행동 순서를 담습니다. 복합 질문에는 요청한 두 부분을 모두 답합니다.
- 같은 의미의 문장을 재사용합니다. 같은 유형의 서로 다른 답변에 정확히 같은 문장이 있으면 ‘공통’으로 표시합니다. 다른 주제에서 재사용하는 문장도 포함합니다.
- 핵심 암기는 8개 묶음의 43개 표현으로 정리했습니다. 각 표현은 실제 질문별 답변에 존재하며, 설명과 한국어 뜻을 함께 제공합니다.
- 기존 159개 질문 ID와 설문 설정은 유지했습니다. 미용실·치과 상황은 각자의 영·한 질문과 완성 답변으로 확인할 수 있습니다.

## 연습 방법

영어 질문 → 한국어 번역으로 요구 확인 → 질문 유형 확인 → MP(첫 핵심 답변) → 부연설명 → 마무리 순서로 연습합니다. 답변은 대부분 5~7문장이며, 질문에 따라 4문장 또는 8문장인 답변도 있습니다. 화면에 나온 완성 답변을 이어 말하면 하나의 답변이 됩니다. 공통 문장은 이미 적절한 위치에 들어 있으므로 다른 답변에서 따로 가져올 필요가 없습니다.

예를 들어 집 묘사는 방·가구·밝기를 설명하고, 집 일과는 저녁 식사·YouTube·정리·취침을 순서대로 말합니다. 같은 집이 주제여도 질문 유형이 다르면 답변의 내용도 구분합니다.

5~7문장은 이번 자료에서 주로 사용하는 학습용 길이 기준입니다. 문장 수만으로 IM2를 보장하지 않습니다. 실제 질문이 요구하는 내용에 맞게, 이해 가능한 말로 대답하는 연습에 사용하세요. ‘필수·보강’은 자료 안의 학습 우선순위이며 실제 출제 여부를 뜻하지 않습니다.

자세한 사용법은 [STUDY_GUIDE.md](STUDY_GUIDE.md)를 확인하세요.

## 질문의 출처와 작성 범위

영어·한국어 질문은 기존 준비 주제를 바탕으로 **독자적으로 작성한 연습 문항**입니다. 공개 안내의 질문 기능과 형식을 참고했으며, 비공개 문제은행에 접근하거나 실제 기출 원문임을 검증한 자료가 아닙니다. 출제 빈도·실제 문항 번호·출제 가능성을 보장하지 않습니다.

- [ACTFL OPIc 공식 안내](https://www.actfl.org/assessments/postsecondary-assessments/oral-proficiency-interview-computer-opic): 말하기 기능, 내용·맥락 적합성, 이해 가능성, 구성 등을 종합적으로 평가한다는 안내를 확인했습니다.
- [ACTFL OPIc Familiarization Guide](https://www.actfl.org/uploads/files/general/OPIc_Familiarization_Guide.pdf): 설문 주제와 익숙한 일상·경험·상황 대응에 관한 설명을 참고했습니다.
- [OPIc 공식 사이트 공개 학습 가이드(2016)](https://www.opic.or.kr/senior/mail/2016/0729/images/a/opic_guide.pdf?opicnativepopup=true): 묘사·비교 및 상황을 제시한 정보 문의·문제 해결 질문 형식을 참고했습니다. 과거 자료이므로 최신 출제 빈도의 근거로 사용하지 않았습니다. 원문의 질문과 모범답안을 대량 복제하지 않았습니다.

## 파일 구성과 실행

- `script-data.js`: `questionEn`, 한국어 `question`, `type`, 완성 `answer`, 흐름 `hint`, 유형별 `scriptGroups`, 롤플레이 `roleplaySections`, 핵심 표현과 출처.
- `app.js`: 영·한 질문, 유형과 문장 수 표시, 공통 문장 표시, 검색·복사·연습.
- `index.html`, `styles.css`: 화면 구조와 반응형 스타일.
- `STUDY_GUIDE.md`: 학습 순서와 답변 유형별 사용법.

답변 배열의 각 항목은 한 문장입니다. 첫 항목은 MP, 마지막은 마무리, 가운데 항목은 모두 부연설명입니다. 복사 버튼은 표시된 완성 답변 전체를 복사합니다. 검색은 영어·한국어 질문, 답변, 유형, 변형 질문을 모두 포함합니다.

로컬 실행: `python -m http.server 8000`. GitHub Pages는 main 브랜치 루트에서 배포합니다.
