# OPIc 5-5 최소암기 스크립트

18개 주제, 질문 159개를 연습하는 정적 웹페이지입니다. v38에서는 전체 스크립트를 첫 화면으로 삼고, 비슷한 질문을 그 안에서 함께 배치했습니다. 질문에 맞는 도입을 유지하면서 같은 내용의 부연설명과 마무리를 같은 표현으로 맞췄습니다.

## 연습 방법

각 답변을 **MP → 필수 부연설명 → 마무리** 순서로 그대로 읽습니다. 익숙해지면 부연설명과 마무리 사이의 선택 문장 0~2개를 추가합니다.

- **전체 스크립트(첫 화면)**: 유사 질문끼리 연속 배치. 같은 묶음의 둘 이상 답변에 정확히 같은 문장이 나오면 답변 안에 ‘공통’ 표시.
- **핵심 암기**: 8개 묶음의 기본 27문장·추가 17문장. 모두 질문별 답변에서 가져온 문장입니다.
- **문제 연습**: 질문과 한국어 흐름 힌트.
- **시험 전 설문**: 현재 준비 주제에 맞는 선택 기록.

‘공통’ 문장은 이미 해당 답변의 적절한 위치에 들어 있습니다. 따로 골라 붙일 필요가 없습니다. 같은 묶음 안에서도 일부 문장만 같을 수 있습니다. 기본 답변의 끝부분 전체가 같으면 그 문장 수를 별도로 표시합니다.

이 묶음은 학습용 분류이며 실제 출제 순서를 예측하지 않습니다. OPIc은 주제별 2~3문항의 testlet을 사용하지만 개인별 조합은 달라집니다. [ACTFL 기술 보고서](https://www.actfl.org/uploads/files/general/Documents/assessments/acereports/OPIc_Report_Part_A_General_Information_2023.pdf)를 참고하세요.

## 답변 원칙

첫 문장은 사건·행동·차이·용건 등 질문의 요구에 바로 답합니다. 감정은 자연스러운 곳에서 표현합니다. 짧은 답변만으로도 비교의 양쪽, 문제의 조치·결과, 절차의 필요한 단계가 들어가게 구성합니다.

반복되는 표현은 같은 문장으로 연습합니다. 카페의 첫 방문·최근 방문, 빠른 음악·느린 음악, 은행 방문·카드 문제처럼 내용이 맞는 질문에서 설명을 재사용합니다. 평소 행동과 과거 경험은 필요한 시제를 바꿉니다.

집 휴가와 국내여행은 주로 혼자 쉬는 설정입니다. 해운대 생일 선물, 가족·친구 모임은 별개 경험입니다. `watch YouTube`, `check my phone`을 재사용하고, 휴대폰 사용법을 설명할 때는 ‘휴대폰으로 휴대폰을 확인한다’는 중복을 피하도록 문장을 나눴습니다.

## 파일 구성

- `script-data.js`: 159개 질문과 답변, `supportCount`, 주제 안의 `scriptGroups`, 핵심 암기 문장.
- `app.js`: 그룹별 답변 표시, 정확히 일치하는 공통 문장 표시, 검색·복사·연습.
- `index.html`, `styles.css`: 화면 구조와 반응형 스타일.
- [STUDY_GUIDE.md](STUDY_GUIDE.md): 최소암기 연습법.

첫 문장은 MP, 그다음 `supportCount`개는 필수 부연설명, 마지막은 마무리입니다. 나머지 중간 문장이 선택 문장입니다. 복사는 선택 문장까지 포함합니다. 미용실/치과 변형도 해당 상황에 맞게 표시하고 복사할 수 있습니다.
